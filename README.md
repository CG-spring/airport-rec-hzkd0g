## 什么是机场？

"机场"是中文互联网社区对**代理节点订阅服务**的俗称。本质上，机场服务商在境外部署大量代理服务器节点，通过特定的加密协议（如 Shadowsocks、Trojan、V2Ray VMess、Hysteria2 等）将流量传输给用户。用户只需在客户端中添加订阅地址，即可自动获取最新节点列表，实现一键切换与科学上网。

机场的核心优势在于**零技术门槛**：用户无需懂 Linux、无需会配置服务器，复制粘贴订阅链接即可使用。同时，机场服务商通常会提供完善的节点维护、线路优化和售后支持。

## 为什么选择机场而非自建 VPS？

在选择科学上网方案时，很多用户会在"机场订阅"和"自建 VPS"之间犹豫不径。以下从多个维度进行对比：

| 对比维度 | 机场订阅 | 自建 VPS |
|---------|---------|---------|
| **技术门槛** | 极低，订阅即用 | 需要 Linux 基础，命令行操作 |
| **初始成本** | 月付 ¥10~50 | 年付 $30~120 |
| **流量额度** | 通常有月限额 | 通常无限流量 |
| **带宽速度** | 多人共享，峰值可能限速 | 独享带宽，性能稳定 |
| **维护成本** | 服务商负责，用户零操心 | 用户自行维护，遇到问题自己排查 |
| **IP 被封风险** | 由服务商统一处理 | 需要自行更换 IP 或重新购买 |
| **适用场景** | 日常浏览、社交娱乐 | 大流量下载、自建节点、高级定制 |
| **节点数量** | 通常 20~200+ 节点 | 通常 1~3 个节点 |
| **协议支持** | 多协议自动切换 | 需手动配置 |

**结论**：对于大多数普通用户，机场订阅是更经济、更省心的选择；如果你有技术基础且有大流量需求，自建 VPS 灵活性更高。本仓库聚焦于帮用户筛选**靠谱的机场服务商**，让你少走弯路。

## 如何快速接入使用

### Step 1：获取订阅地址

从服务商处获取你的**专属订阅链接**（通常为形如 `https://xxx.com/api/v1/client/subscribe?token=xxxx` 的地址）。

> 🔒 请妥善保管订阅链接，避免泄露给他人。

### Step 2：导入订阅到客户端

不同客户端导入方式略有不同，详见下方[推荐客户端全平台指南](#推荐客户端全平台指南)。

通用步骤：
1. 打开客户端 → 设置/偏好设置
2. 找到"订阅"或"节点管理"选项
3. 点击"添加订阅"，粘贴订阅链接
4. 确认后自动拉取节点列表
5. 选择节点，启用代理

### Step 3：配置规则分流（进阶）

进阶用户可配置**分流规则**，实现：
- 国内网站直连，境外网站走代理（速度更快）
- 广告拦截（屏蔽广告域名）
- 自定义订阅规则集（从 [ClashHub](https://clashhub.net) 等获取）

推荐规则集：
- `https://cdn.jsdelivr.net/gh/Loyalsoul/Rule@master/Rule-Resolve.yaml`（综合分流）
- `https://cdn.jsdelivr.net/gh/blackmatrix7/ios_rule_script@master/rule/Clash/Netflix/Netflix.yaml`（Netflix 专用）

## 线路类型深度解析

### 🏆 IPLC 专线 — 顶级体验

IPLC（International Private Leased Circuit，国际专线）是通过物理光纤直连跨境的网络专线，不经过公网抖动，延迟极低，稳定性极佳。适合对速度要求极高的用户。

**优势：**
- 极低延迟（香港 ~25~40ms）
- 带宽稳定，峰值不降速
- 晚高峰依然流畅
- 不受国际出口带宽波动影响

**劣势：**
- 成本高，相应套餐价格较贵
- 节点相对 BGP 较少

### ⭐ IEPL 专线 — 高性价比之选

IEPL（International Ethernet Private Line）是基于以太网技术的国际专线，成本低于 IPLC，但性能依然出色，是目前最主流的优质线路方案。

### 🔷 BGP 中继 — 均衡方案

BGP（Border Gateway Protocol）通过智能路由选择最优路径，在公网传输。BGP 中继线路在多数时段表现优秀，晚高峰可能出现波动，但对于日常使用完全足够。价格亲民，是入门首选。

### 📡 普通线路 — 基础可用

普通线路多为 CN2 GIA 或普通优化线路，速度和稳定性一般，适合对价格敏感、流量需求不大的用户。

### 📊 线路选择建议总结

```
追求极致体验 → IPLC/IEPL 专线节点
日常使用性价比 → BGP 中继节点
预算有限尝鲜 → 普通线路
晚高峰经常卡顿 → 优先选 IPLC 专线
```

## 常见问题 FAQ

### Q1: 订阅链接失效了怎么办？

订阅链接通常在以下情况失效：
- 服务商更换域名或 API 版本
- 账户欠费或被封禁
- Token 过期

**解决方法：** 联系服务商客服获取新的订阅链接，或登录官网重新生成。

### Q2: 节点速度突然变慢？

可能原因：
- 本地网络高峰拥堵
- 所选节点被临时限速或故障
- 服务商侧网络调整

**解决方法：** 尝试切换到其他节点（如香港换日本），或等待服务商修复。多数优质服务商会在 TG 群或官网公告通知。

### Q3: 订阅后没有流量怎么回事？

检查：
1. 账户是否已激活/充值
2. 套餐是否已生效
3. 流量是否用尽（部分套餐有月流量限制）
4. 订阅地址是否粘贴正确

### Q4: 如何防止订阅链接泄露？

- 不要在公开渠道（论坛、群聊）分享你的订阅链接
- 定期在服务商后台重置订阅 Token
- 使用强密码保护账户

### Q5: 可以同时在多个设备使用吗？

取决于套餐策略：
- **单人套餐**：通常限制同时在线 1~3 台设备
- **家庭/团队套餐**：支持 5~10 台设备同时在线
- **无限制套餐**：不限制设备数

请查看你购买的具体套餐说明。

### Q6: 遇到 500/502/503 错误？

通常是服务商节点维护或服务端过载。等待 5~15 分钟后再试，或联系客服反馈。
